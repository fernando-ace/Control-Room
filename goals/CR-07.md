# CR-07: Mobile and responsive polish

## Objective and context

Perform a complete mobile usability pass for approximately 390 px wide screens. Inspect the current UI, CSS, and browser validation before editing.

## Dependencies

None. Coordinate with CR-02 and CR-03 to avoid simultaneous edits to shared components/styles.

## Invariants

Preserve game rules, server authority, role-specific information, accessibility, and desktop behavior. No horizontal overflow at the target width.

## Scope

Review entry, lobby, briefing, gameplay controls, objectives, alerts, post-game, and retry. Improve touch targets, readable hierarchy, safe scrolling, and responsive layout throughout.

## Non-goals

Do not redesign mission rules, remove information to fit, or change security/reconnect behavior.

Do not modify `ROADMAP.json`, other goal prompts, goal CLI scripts, or workflow documentation as part of this feature.

## Definition of done

- The complete flow is usable at about 390 px, with no horizontal overflow.
- Controls remain reachable and legible; alerts and objectives remain visible/actionable.
- Desktop layout remains sound and browser checks cover the complete flow.

## Validation and completion

Inspect implementation and tests rather than assuming filenames. Run lint, typecheck, unit/API tests, build, and desktop/mobile browser validation as available; run `git diff --check`. Do not weaken test assertions. If criteria cannot be met, report incomplete. Review and commit locally; do not push or deploy.
